Chapa Quente 🔥

Site institucional e cardápio digital de uma hamburgueria fictícia, feito como projeto da disciplina de Front End (Análise e Desenvolvimento de Software, Universidade Católica de Brasília).

Funcionalidades
Site institucional com carrossel de destaques e cardápio em destaque
Cardápio digital por categorias (Burgers, Porções, Drinks, Sobremesas)
Sacola de compras, favoritos e histórico de pedidos (salvo no navegador)
Pedido para entrega ou retirada, com pagamento simulado (Pix, cartão ou dinheiro)
Envio do pedido pronto para o WhatsApp da loja
Modo administrador para cadastrar itens
Transição animada entre o site e o cardápio, com suporte a "reduzir movimento"
Tecnologias

HTML5, CSS3 e JavaScript puro (sem frameworks), com localStorage para guardar dados no navegador.

Como rodar

Baixe o projeto e abra o index.html no navegador. Não precisa instalar nada.

Configuração

No arquivo config.js: número do WhatsApp da loja, senha do modo administrador e taxa de entrega.

Aviso

Projeto acadêmico. A loja, os dados e o pagamento são fictícios: nada é cobrado nem enviado a servidor.
